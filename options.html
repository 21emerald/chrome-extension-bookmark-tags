📖 Usage Guide

Quick Start

After installing the extension, click the extension icon on any page to open the popup. If the page is not bookmarked, you'll see the title, suggested tags, and a "Bookmark" button. Click a tag to bookmark the page with that tag.

Tag Management

Tags are the core organizing tool. Each tag belongs to a group (or "Ungrouped" if none is specified).

  • Create a group: Go to "Tag Manager" tab, type a group name in the input at the top, and click "Add Group". Groups can be drag-reordered.
  • Create a tag: Click "+" at the bottom of any group, type the tag name and press Enter. Tags can also be drag-reordered within their group.
  • Tag aliases: Click a tag to edit it. In the "Aliases" field, add alternative names. Searching an alias matches the same tag. Example: tag "JavaScript" with alias "JS" — searching "JS" finds all bookmarks tagged "JavaScript".
  • Marked Tags: In the tag edit panel, "Marked Tags" lets you associate one tag with others. When searching for tag A, bookmarks tagged with any of its marked tags will also appear. This creates a hierarchical relationship (e.g., "Frontend" marked with "React", "Vue" — searching "Frontend" also finds "React"/"Vue" bookmarks).
Tip: You can add tags directly from the popup when bookmarking a page, or from the Options search page using the tag picker (🏷️ button).

Site Configuration

Site configs let you write a custom script that runs automatically when you visit a matching page. The script can extract title, tags, preview image, and more.

  • URL Pattern: A regular expression. When the current page URL matches, the script runs. Example: youtube\\.com/watch
  • Script: JavaScript code that can read and modify these pre-defined variables: title, labels, tags, preview, previewVideo. Assign to them to set values.

Example — YouTube:

// URL Pattern: youtube\.com/watch // Extract video title and thumbnail title = document.querySelector('yt-formatted-string.ytd-watch-metadata')?.textContent?.trim() || title; preview = document.querySelector('link[rel="thumbnail"]')?.href || ''; previewVideo = location.href;

Example — GitHub repo:

// URL Pattern: github\.com/[^/]+/[^/]+$ // Extract repo name and topics title = document.querySelector('.js-repo-nav [itemprop="name"]')?.textContent?.trim() || title; const topicEls = document.querySelectorAll('.topic-tag'); tags = Array.from(topicEls).map(el => el.textContent.trim());
Note: Scripts run in the page's MAIN world context, so you can access the full DOM. For pages with strict CSP, script execution may fail. Use the "Debug" feature on the Site Config page to test.

Preview & Video

Each bookmark can have a preview image (preview) and a preview video (previewVideo). These can be set by:

  • Site config scripts (automatically extracted)
  • Manual edit in the popup or Options page

In the Options search page, previews are displayed as thumbnails. Hovering over a card with a previewVideo will play the video. Enable "Auto-play videos" to play all videos without hovering.

Data Sync

Two sync methods are available:

  • Chrome Sync: Uses your Chrome account to sync data across devices. Toggle on in Settings. Limited to ~100KB.
  • Google Drive: Backs up data to your Google Drive app data folder. Supports version tracking and conflict detection. More reliable for large datasets.
